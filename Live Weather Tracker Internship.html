Challenges I solved

Searching 550,000+ villages

Problem
Online place search is slow, rate-limits typing, and misses villages.
Approach
Keep an all-India place dataset inside the app with zero API cost.
Solution
GeoNames data in compressed SQLite & Cloudflare D1 database.
Result
Sub-15ms autocomplete search covering all 550,000+ villages.

App stopped without internet

Problem
One failed API call broke the whole page.
Approach
List what can fail: timeout, no connection, bad reply.
Solution
One function with try / except that raises one clear error.
Result
The user sees a friendly message, not a crash.

Three languages

Problem
English text was hard-coded in the screens.
Approach
Keep every piece of text in one place.
Solution
A dictionary in i18n.py read with t(lang, key).
Result
One dropdown switches English, Hindi, Bhojpuri.
